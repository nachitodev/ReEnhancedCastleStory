## Installation

_If you are packaging the launcher from non-windows platform, you need to install [Wine 1.6](https://www.winehq.org/)_


Run ``bun install`` to install required packages
 

## Usage
Start the launcher running ``bun start``


## Package all the launchers
Run ``bun run package``

## Package Windows 

Run ``bun run pack:win32 or pack:win64``

## Package Linux

Run ``bun run pack:linux32 or pack:linux64``

## Package Mac

Run ``bun run pack:osx``
